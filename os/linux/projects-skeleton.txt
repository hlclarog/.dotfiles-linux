# Directory skeleton for ~/Projects, created by
# restoration_scripts/05-projects-skeleton.sh
#
# One path per line, relative to ~/Projects. Blank lines and # comments are
# ignored. Parent directories are created automatically.
#
# This is DECLARED rather than derived from ~/Win on purpose: the Windows folder
# disappears once migration finishes, and does not exist at all on a fresh
# machine, so deriving it would rebuild nothing exactly when it matters.
#
# NAMING: <project>-<layer>. The project is repeated even though the parent
# directory already carries it, because JetBrains IDEs show the bare folder name
# in their recent-projects list, where "backend" alone would be unreadable
# across fifteen entries. The older "-review-pr-" infix was dropped: these
# checkouts are used for development, not just for reviewing pull requests, and
# for an actual PR review `git worktree add` beats a second clone since it
# shares one .git instead of duplicating the history.
#
# Several local names do not match their repository name, so always clone with
# an explicit destination.
#
# To refresh this list from the current state:
#   cd ~/Projects && find . -mindepth 1 -type d -not -path '*/.git*' \
#     -not -path '*/node_modules*' | sed 's|^\./||' | sort
